# Mp4toMp3

Simple Windows app to convert MP4 files to MP3.

## Features
- Ability to choose bitrate
- Convert MP4 to MP3 or FLAC
- Fast and lightweight
- Uses FFmpeg

## Usage
1. Select file
2. Choose output format and bitrate
3. Convert

## Dependencies
- Qt 6 (Qt Widgets)
- FFmpeg (LGPL/GPL licensed)
FFmpeg source code is available at https://ffmpeg.org
